# Datos de ejemplo

Esta carpeta muestra la estructura de datos que usa el bot (el volumen `DATA_DIR`, `/data` en producción).
**No contiene datos reales.** Para empezar:

```bash
cd bot && npm run init-data            # crea DATA_DIR con esta estructura (no pisa nada existente)
```

Ver `docs/ESTRUCTURA.md` para el detalle de cada carpeta y archivo.
